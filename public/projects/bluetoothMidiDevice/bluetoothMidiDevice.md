This project connects a mobile interface to a small embedded sound system over Bluetooth. Built around an STM32 Nucleo F446RE development board, the device receives note commands from a phone and plays the corresponding sound through a connected speaker.

A companion Flutter application provides a simple way to trigger notes from a piano or drum interface. After connecting the phone to the Bluetooth module, pressing a key sends the corresponding command to the microcontroller, which handles playback. The project combines a mobile UI with embedded communication and audio output in one compact prototype.
